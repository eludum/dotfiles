# dotfiles

Terminal:

install fish shell

```
sudo brew install fish
```

install fzf.fish and tide with fisher: <https://github.com/jorgebucaran/fisher> & <https://github.com/PatrickF1/fzf.fish> & <https://github.com/IlanCosman/tide>

```
curl -sL https://git.io/fisher | source && fisher install jorgebucaran/fisher
brew install fzf
fisher install PatrickF1/fzf.fish
fisher install IlanCosman/tide@v6
```
